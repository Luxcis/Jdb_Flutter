# 排行榜紧凑筛选设计

## 背景

当前排行榜的 Top250 筛选抽屉占用高度偏大，筛选项间距较松；看热播与有码、无码、欧美、FC2 使用了不同的筛选视觉形式。此次调整只优化布局密度与一致性，不改变筛选值、接口参数、即时刷新、Tab 保活或加载状态逻辑。

## 目标

- Top250 抽屉打开后固定占用约三分之二屏幕高度，用户不可继续上拉扩展。
- Top250 类型、年份和起始排名筛选项更紧凑，容纳更多内容。
- 有码、无码、欧美、FC2 的日榜、周榜、月榜分段胶囊更紧凑，同时横向撑满可用宽度。
- 看热播改为同一行左右并排的两个紧凑分段胶囊，与综合排行榜保持一致。
- 窄屏和大字体场景不出现溢出。

## Top250 抽屉

### 高度与滚动

- Modal Bottom Sheet 固定为屏幕可用高度的约 `2 / 3`。
- 不使用可调整高度的 `DraggableScrollableSheet`，避免上拉扩展。
- 保留顶部拖拽提示条，用于表达抽屉可向下关闭。
- 抽屉内容使用内部纵向滚动视图；内容超过固定高度时仅滚动内容。

### 紧凑筛选项

- 类型与年份继续共用一个选择维度。
- 类型、年份、起始排名仍使用 `ChoiceChip`。
- 减小标签横向内边距、Chip 视觉密度、水平间距和换行间距。
- 隐藏 ChoiceChip 的选中对勾，通过选中底色表达状态。
- 标题与分组之间的垂直间距同步缩小。
- `未标「看过」` 开关继续位于内容底部，不改变文案和行为。

## 综合排行榜胶囊

有码、无码、欧美、FC2 继续使用同一个分段选择组件：

- 选项固定为日榜、周榜、月榜。
- 分段胶囊横向撑满页面可用宽度。
- 使用紧凑视觉密度、较小垂直高度和内边距。
- 隐藏选中图标，通过背景色表达选中状态。
- 不改变 `daily`、`weekly`、`monthly` 参数映射。

## 看热播胶囊

看热播移除“范围”和“周期”行标题，改为同一行左右并排：

1. 左侧胶囊：高分、全部，占可用宽度约 `2 / 5`。
2. 右侧胶囊：日榜、周榜、月榜，占可用宽度约 `3 / 5`。

两个胶囊使用与综合排行榜相同的紧凑分段样式，并始终保持同一行。二者之间保留小间距，通过隐藏选中图标、缩小横向内边距和 `2 : 3` 弹性约束确保窄屏及 1.5 倍字体场景不溢出，不允许自动换成上下排列。

接口参数保持不变：

- 左侧映射 `filter_by=high_score|all`。
- 右侧映射 `period=daily|weekly|monthly`。
- 任一选项变化后继续立即刷新列表。

## 组件方案

为共享 `SortSegmented` 增加可选的紧凑配置，默认值保持现有页面行为：

- `compact`：启用紧凑视觉密度、缩小内边距并隐藏选中图标。
- `expanded`：让分段胶囊撑满父容器宽度。

排行榜按场景组合：

- 综合排行榜：`compact + expanded`。
- 看热播：两个 `compact` 组件分别放入 `2 : 3` 的弹性布局。
- 其他现有 `SortSegmented` 调用不传新参数，视觉不变。

Top250 的 ChoiceChip 紧凑样式仅保留在筛选抽屉内部，避免影响其他页面。

## 测试与验收

Widget 测试应覆盖：

- Top250 抽屉高度约为测试屏幕的三分之二，且不存在 `DraggableScrollableSheet`。
- 抽屉内容仍可滚动到底部并操作起始排名与未看开关。
- 看热播只渲染两个 `SegmentedButton`，普通手机宽度下处于同一行。
- 看热播选择周榜后仍发送 `filter_by=high_score&period=weekly`。
- 有码、无码、欧美、FC2 的分段胶囊撑满可用宽度。
- 窄屏大字体下不出现布局异常。
