# 分类筛选面板三分之二高度设计

## 目标

分类页面打开筛选面板后，面板固定占可视屏幕高度的三分之二，避免接近全屏。

## 设计

- 保留现有 `showModalBottomSheet`、安全区域、拖动手柄和内部滚动逻辑。
- 面板高度由当前屏幕高度乘以 `2 / 3` 得出。
- 面板保持固定高度，不增加拖动扩展到全屏的行为。
- 筛选内容超出面板时继续使用现有内部列表滚动。
- 不修改动态标签、即时筛选、各 Tab 独立状态或影片分页逻辑。

## 验收

- 在高度为 844px 的 Widget 测试视口中，底部面板高度约为
  `844 × 2 / 3 = 562.67px`。
- 打开面板后仍能显示动态筛选内容。
- 点击筛选项仍即时发送请求，且面板保持打开。
- 分类页面现有 Widget 测试和全量测试通过，静态分析无问题。
