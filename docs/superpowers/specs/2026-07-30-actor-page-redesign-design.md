# 演员页面改版设计

## 目标

根据官方客户端参考图重做演员页面：

- 推荐页正确展示新人、月排名、Fanza(DMM) 推荐三个独立分区。
- 分类演员列表采用三列圆角方形头像网格，并在接近底部时自动加载下一页。
- 仅“有码(女)”提供紧凑的身体条件筛选底部面板。
- 全局演员头像统一为圆角方形样式。
- 演员名称统一按 `name_zht > name` 的优先级展示。

## 范围

本次包含：

- 演员推荐与分类列表的数据模型、接口参数、分页和错误处理。
- 演员页面及其筛选面板。
- 全局演员头像、演员卡片和演员网格样式。
- 复用 `SectionHeader` 已有的可选尾部点击回调。
- 受全局演员头像影响的演员详情、搜索、收藏和影片详情演员展示。
- 聚焦测试、完整测试和静态分析。

本次不包含：

- “月排名”右侧“全部 >”的实际路由跳转。
- 搜索按钮及演员搜索交互的新增或改版。
- 接口未返回的推荐更新日期。
- 新增第三方依赖。

## 接口契约

### 推荐演员

请求：

```text
GET /api/v1/actors/recommend
```

无需 Bearer Token。未登录用户也可直接查看推荐内容。

响应中的三个数组必须独立解析：

- `new_actors`：新人。
- `monthly_actors`：月排名。
- `recommend_actors`：Fanza(DMM) 推荐。

不得展平后将同一份数据重复用于多个分区。

### 分类演员

请求：

```text
GET /api/v1/actors
```

所有请求固定发送：

| 参数 | 值 |
| --- | --- |
| `type` | `"all"`、`"0"`、`"1"` 或 `"2"` |
| `gender` | `"all"`、`"0"`（女）或 `"1"`（男） |
| `page` | 从 1 开始的页码 |
| `limit` | 固定为 60 |

Tab 映射：

| Tab | `type` | `gender` |
| --- | --- | --- |
| 有码(女) | `"0"` | `"0"` |
| 有码(男) | `"0"` | `"1"` |
| 无码 | `"1"` | `"all"` |
| 欧美(女) | `"2"` | `"0"` |
| 欧美(男) | `"2"` | `"1"` |

只有“有码(女)”允许发送筛选范围。筛选参数仅在范围偏离默认值时发送，格式统一为 `"min,max"`：

| 参数 | 默认范围 |
| --- | --- |
| `age` | 19–65 |
| `height` | 130–185 |
| `cup` | 0–15 |
| `bust` | 70–120 |
| `waist` | 50–90 |
| `hips` | 70–120 |

罩杯内部使用整数 0–15；界面将两个端点映射为 A–P。

## 演员名称规范

演员响应进入业务层时统一规范化名称：

1. 优先使用去除首尾空白后非空的 `name_zht`。
2. 否则使用去除首尾空白后非空的 `name`。
3. 两者均缺失或为空时使用项目现有安全兜底值，不能导致 JSON 解析崩溃。

该规则必须覆盖推荐列表、分类列表、搜索结果、收藏列表、影片详情演员区和演员详情，不在单一页面内重复实现。

## 架构

### 数据模型

新增类型化 `ActorRecommend`，分别持有新人、月排名和 Fanza(DMM) 推荐演员。

新增不可变的 `ActorFilter`：

- 保存六个范围。
- 提供默认值、`copyWith` 和重置能力。
- 负责判断每个范围是否为默认值。
- 负责只将非默认范围编码为接口查询参数。

演员分类由一个明确的配置对象表示，配置包含 `type`、`gender` 和是否支持筛选，避免页面内散落字符串判断。

### Service

`ActorService.getRecommends()` 返回 `ActorRecommend`。

`ActorService.getActors()` 接收分类配置、页码和可选 `ActorFilter`，统一构造请求：

- 始终发送 `type`、`gender`、`page`、`limit=60`。
- 非“有码(女)”忽略筛选对象。
- “有码(女)”只发送偏离默认值的范围参数。

服务层将接口 `actors` 数组解析为 `ActorSummary`，并返回分页结果。

### 页面状态

五个分类 Tab 各自拥有独立的分页控制器和滚动状态：

- 首次可见时请求第 1 页。
- 切换 Tab 保留已加载数据和滚动位置。
- 下拉刷新只刷新当前 Tab。
- 接近底部时自动请求下一页。
- 应用筛选仅重载“有码(女)”并从第 1 页开始。

推荐 Tab 独立管理加载、成功、空数据和失败状态。

## 分页策略

接口契约只保证返回 `current_page`，未保证 `total_pages`。分类列表按每页数量判断是否还有下一页：

- 返回少于 60 条：停止加载。
- 返回 60 条：允许请求下一页。
- 下一页为空：停止加载。

若最后一页恰好为 60 条，会多发一次空页请求，这是在当前接口契约下可接受且不会丢数据的行为。

自动加载触发点为滚动区域距离底部约 200px。控制器必须防止重复并发请求。

## 视觉与交互

### 页面结构

顶部保留六个横向滚动 Tab：

```text
推荐 / 有码(女) / 有码(男) / 无码 / 欧美(女) / 欧美(男)
```

分类 Tab 不再嵌套第二层 `Scaffold` 或 `AppBar`。

### 推荐页

推荐页依次展示：

1. 新人。
2. 月排名。
3. Fanza(DMM) 推荐。

三个分区均使用各自接口数组和共享演员卡片。

“新人”不显示无法由接口可靠取得的更新日期。

“月排名”使用全局 `SectionHeader`，右侧显示“全部 >”。直接复用组件已有的 `onTrailing` 可选回调；演员页本次传入空回调以保留点击反馈，但不执行导航。

未提供尾部点击回调的现有 `SectionHeader` 消费者保持原行为与视觉。

### 演员网格与卡片

- 手机端使用三列等宽网格。
- 图片保持 1:1，使用约 8px 圆角和 `BoxFit.cover`。
- 名称位于图片下方，居中、单行、溢出省略。
- 卡片不使用阴影或额外背景。
- 卡片尺寸由网格约束决定，不再写死 72×72。
- 网格按父级宽度响应式计算，窄屏和字体放大时不得溢出。

### 全局演员头像

`ActorAvatarImage` 自身负责：

- 圆角方形裁切。
- 1:1 视觉约束由调用方尺寸或网格约束提供。
- `BoxFit.cover`。
- 现有缓存、解密、加载失败占位图和语义标签。

调用方不得再用 `ClipOval` 将演员头像裁成圆形。演员详情页顶部 84×84 头像也改为圆角方形。

### 筛选入口与面板

筛选入口仅在“有码(女)”显示，位于演员网格内容顶部右侧，不额外占用一整层 AppBar。

点击后打开 Material 3 模态底部面板：

- 支持拖动与安全区。
- 顶部显示“筛选”和“重置”。
- 六行依次为年龄、身高、罩杯、胸围、腰围、臀围。
- 每行使用紧凑的“标签 + RangeSlider + 当前范围”布局。
- “重置”恢复所有默认范围。
- 用户拖动时只修改面板的草稿值。
- 点击“应用筛选”后关闭面板并发起一次第 1 页请求。
- 直接关闭面板时丢弃未应用的草稿值。

面板使用主题颜色和文本样式，支持亮色、暗色主题以及系统字体缩放。所有滑杆、重置和应用操作提供明确语义标签。

## 加载、空状态与错误处理

### 推荐页

- 首次加载显示居中加载状态。
- 三个数组均为空时显示统一空状态。
- 请求失败显示统一错误和重试。
- 异步完成前检查组件仍处于挂载状态。

### 分类列表

- 首屏失败且无已有数据时显示全页错误重试。
- 后续页失败保留所有已加载演员，在网格末尾显示轻量重试入口。
- 自动加载和手动重试不得并发请求同一页。
- 应用筛选时保留旧列表并显示刷新状态；请求成功后原子替换，失败时保留旧列表和已应用筛选条件，并允许重试。
- 下拉刷新失败时同样保留旧列表。

## 共享组件

### `SectionHeader`

现有组件已经提供 `trailing` 和 `onTrailing`，本次直接复用：

- 有回调且存在尾部文字时，尾部区域可点击并展示视觉反馈。
- 无回调时保持现有静态尾部文字行为。
- 点击区域包含尾部文字与箭头。
- 演员页的“全部 >”传入空回调，不导航。
- 不修改 `SectionHeader` 的公开 API。

### 分页控制器与演员网格

分页控制器补充以下通用状态：

- 首屏加载。
- 保留数据刷新。
- 页尾加载。
- 页尾错误及重试。
- 基于本页返回数量判断 `hasMore` 的能力。

共享行为必须向后兼容现有电影及其他分页列表。

- 推荐接口三个数组独立解析。
- `name_zht` 和 `name` 都存在时选择 `name_zht`。
- `name_zht` 缺失、为空或仅含空白时回退到 `name`。
- 两个名称均无效时安全解析。
- 五个分类 Tab 的 `type/gender` 映射正确。
- 所有分类请求均发送 `page` 和 `limit=60`。
- 默认筛选不发送六个可选参数。
- 每个非默认筛选按 `"min,max"` 编码。
- 非“有码(女)”不会发送筛选参数。
- 少于 60 条停止分页，60 条继续，空页停止。

- 只有“有码(女)”显示筛选入口。

- 重置恢复默认范围，关闭不应用，应用后从第 1 页刷新。

## 验收标准

- 未登录用户打开演员推荐页可看到三个真实且互不混用的推荐分区。
- 五个分类 Tab 使用正确的 `type/gender/page/limit=60` 请求。
- 分类列表连续滚动时自动分页且不重复请求。
- 只有“有码(女)”能打开并应用六项紧凑筛选。
- 默认范围不进入请求参数，非默认范围格式准确。
- 所有演员展示优先使用非空 `name_zht`。
- 全局演员头像为圆角方形，图片不拉伸，失败时仍有正确占位图。
- “月排名”显示可点击的“全部 >”，本次点击不跳转。
- 聚焦测试、完整测试、静态分析和差异检查均通过。
