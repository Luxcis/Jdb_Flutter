# 搜索结果影片筛选设计

## 目标

调整综合搜索结果页的“影片”Tab，使其严格通过 `GET /api/v2/search` 获取影片结果，并在列表顶部提供类型、筛选、排序三组单选条件。影片列表延续项目现有影片网格样式，支持滚动接近底部时自动加载下一页。

## 范围

本次仅调整搜索结果页的影片 Tab：

- 不改变搜索入口页、搜索历史和近期热搜。
- 不改变演员、系列、片商、导演、清单和番号 Tab。
- 不新增第三方瀑布流或分页依赖。
- 所有新增界面文案直接使用中文，遵循项目约定。

## 接口契约

影片搜索调用：

```text
GET /api/v2/search
```

每次请求固定发送以下查询参数：

| 参数 | 值 |
| --- | --- |
| `q` | 当前搜索关键词 |
| `type` | `movie` |
| `movie_type` | 当前类型值 |
| `movie_filter_by` | 当前筛选值 |
| `movie_sort_by` | 当前排序值 |
| `page` | 从 1 开始的当前页码 |
| `limit` | `48` |

类型映射：

| 界面文案 | 参数值 |
| --- | --- |
| 全部 | `all` |
| 有码 | `0` |
| 无码 | `1` |
| 欧美 | `2` |
| FC2 | `3` |
| 动漫 | `4` |

筛选映射：

| 界面文案 | 参数值 |
| --- | --- |
| 全部 | `all` |
| 可播放 | `can_play` |
| 含磁链 | `magnets` |
| 字幕 | `subtitle` |
| 单体 | `single` |

`single` 是用户对现有 OpenAPI 枚举的明确补充，客户端按该值原样发送。

排序映射：

| 界面文案 | 参数值 |
| --- | --- |
| 相关度 | `relevance` |
| 发布时间 | `release` |
| 更新时间 | `update` |
| 评分 | `score` |

默认筛选组合为 `movie_type=all`、`movie_filter_by=all`、`movie_sort_by=relevance`。

## 架构

在 `lib/features/search/` 内按职责拆分：

- 筛选模型负责保存三个单选值以及中文标签和接口值映射。
- 搜索服务负责构造 `/api/v2/search` 请求、解析 `movies` 和分页元数据。
- 影片 Tab 只管理当前筛选状态、分页控制器和界面交互。
- 现有 `MovieGridView` 与 `PaginationController<MovieSummary>` 继续负责影片网格、下拉刷新、加载中状态、失败重试和滚动加载更多。

搜索模块通过自己的模型和服务隔离综合搜索契约，不复用分类页的 `CategoryFilter`。分类页使用 `filter_by` 组合字符串，而综合搜索使用三个独立的 `movie_*` 参数，强行复用会增加错误映射风险。

## 界面与交互

影片 Tab 由顶部筛选区和下方影片网格组成。

顶部筛选区固定显示三行：

1. `类型`：全部、有码、无码、欧美、FC2、动漫。
2. `筛选`：全部、可播放、含磁链、字幕、单体。
3. `排序`：相关度、发布时间、更新时间、评分。

每行左侧显示分组标题，右侧为单行紧凑 `ChoiceChip`。窄屏放不下时，右侧选项区域允许横向滚动，保持每个分组只占一行。选中项使用 Material 3 主题的选中状态，不显示额外勾选图标。

用户切换任意条件后：

1. 更新对应的单选值。
2. 取消旧请求结果对当前列表的影响。
3. 清空旧条件的影片并请求新条件第 1 页。
4. 滚动接近底部时继续请求第 2、3 页并追加结果。

重复点击当前已选条件不触发请求。

## 分页与响应解析

响应由网络层解包后，服务读取 `data.movies`、`current_page`、`total_pages` 和总数：

- `movies` 缺失时按空列表处理。
- `current_page` 缺失时使用本次请求页码。
- `total_pages` 存在时以它判断是否还有下一页。
- `total_pages` 缺失时，如果本页返回 48 条，则暂定还有下一页；不足 48 条则停止加载。
- 总数优先读取 `total_count`，其次读取 `total`，最后使用当前已解析条数。

`PaginationController.reloadWith` 的 generation 机制用于忽略切换筛选前仍在途的旧响应，避免不同筛选结果混入同一列表。

## 加载与错误处理

- 首次加载和切换筛选后，列表为空时显示居中加载指示器。
- 首次请求失败时显示现有错误重试组件。
- 加载下一页失败时保留已加载影片，并显示页尾重试按钮。
- 下拉刷新使用当前筛选组合重新请求第 1 页。
- API 异常继续交由现有 `ApiClient` 和共享拦截器处理，不在页面重复实现网络错误转换。

## 测试

新增或扩展以下测试：

1. 搜索服务测试：断言默认组合完整发送 `q/type/movie_type/movie_filter_by/movie_sort_by/page/limit`。
2. 搜索服务测试：断言 `single` 原样发送，并正确解析影片与分页字段。
3. 搜索服务测试：断言缺少 `total_pages` 时使用每页 48 条推断下一页。
4. Widget 测试：断言影片 Tab 显示三行标题及所有指定选项，并且默认项正确选中。
5. Widget 测试：切换类型、筛选、排序分别重新请求第 1 页并携带正确参数。
6. Widget 测试：重复点击已选项不重复请求。
7. 分页回归测试：滚动接近底部后请求下一页并追加影片。
8. 窄屏和放大字体测试：三行筛选区不产生布局溢出。
