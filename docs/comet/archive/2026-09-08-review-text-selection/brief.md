# 目标

影片评论列表中的评论卡片（ReviewTile）支持文本选择：长按评论正文进入选择态并展示操作菜单（复制等），
用户可选取并复制评论文本。

# 范围

- 评论正文（`Review.content` 在 `lib/core/widgets/review_tile.dart` 的 `_ExpandableReviewContent` 渲染部分）支持长按进入选择态、拖动选择手柄调整范围、展示文本选择操作菜单并复制所选文本。
- 实现位于共享组件 `ReviewTile`：影片详情页短评列表（`MovieReviewList`）与"看短评"页（`ReviewsPage`）同时生效，行为一致。
- 保留现有"点击正文展开/收起"交互：未选中文字时点击正文仍触发展开/收起；已选中文字时点击正文仅清除选择、关闭菜单，不触发展开/收起。
- 折叠态（超过 5 行省略号截断）下长按正文可选择其可见文本。
- 长按进入选择，垂直滑动仍滚动列表，不改变列表滚动行为。

# 非目标

- 不支持选择作者名、评分、影片信息区、点赞行、日期等正文以外的卡片元素。
- 不新增复制/全选之外的扩展菜单动作（翻译、分享等）。
- 不改变点赞流程、登录提示、展开/收起按钮、影片信息跳转等既有行为。
- 不改变列表滚动、分页加载等既有行为。
- 不引入 flutter_localizations 或 .arb 本地化框架。

# 验收示例

- A1: 影片详情页短评列表中长按评论正文，正文进入选择态（出现选择手柄）并展示含"复制"的操作菜单；点击"复制"后剪贴板内容与所选文本一致。
- A2: "看短评"页长按评论正文，同样进入选择态并可通过菜单复制所选文本。
- A3: 超过 5 行折叠显示（省略号截断）的评论正文，长按其可见部分可进入选择态并复制所选可见文本。
- A4: 未选中文字时点击正文仍触发展开/收起（折叠点击展开、展开点击收起）；已选中文字时点击正文仅清除选择并关闭菜单，展开/收起状态不变。
- A5: 不超过 5 行的短评正文长按可选择并复制；点赞、展开/收起按钮、影片信息跳转等既有交互保持不变。

# 约束与不变量

- 遵循项目规则：Material 3、中文硬编码文案、无本地化框架、无触觉反馈。
- 网络与数据层不变更；仅改动评论卡片展示层。
- 既有测试全部保持通过，新增行为有 widget 测试覆盖（`test/core/widgets/review_tile_test.dart`）。

# 决策

- D1: 生效范围为共享组件 `ReviewTile`，影片详情页短评列表与"看短评"页同时生效。理由：用户确认两处行为一致优于仅改单页。
- D2: 保留"点击正文展开/收起"，通过原始指针事件判定点击；选择态激活时点击仅清除选择。理由：用户确认保留现有交互，避免行为回退。
- D3: 操作菜单使用文本选择默认菜单（复制/全选），菜单标签按项目约定硬编码中文。理由：满足"展示操作菜单"，与项目中文文案约定一致，不引入本地化框架。
- D4: 仅评论正文可选择。理由：用户需求聚焦评论文本，其他卡片元素无选择需求。
- D5: 通过长按进入选择而非点击，垂直拖动仍由列表滚动接管。理由：符合移动端文本选择惯例，避免与滚动冲突。
