# 影片详情页剧照缩略图（预告片 / 剧照区）——滚动稳定性

## 概述

影片详情页「预告片 / 剧照」区（`MovieScreenshotSection`）横向展示预告片封面缩略图与剧照缩略图。本规格在 `detail-still-autoscale` 的「按实际宽高比自适应」能力之上，补充滚动稳定性要求：剧照列表长度不限，横向滚动在向前与回退方向上都必须稳定，不允许因缩略图重新挂载而出现闪回。

## 滚动稳定性

- 剧照缩略图的宽高比以 URL 为键被记忆：某 URL 的图片真实比例一经解码，与会话期内所有该 URL 的缩略图实例共享，包括懒构建列表中被销毁又重新挂载的实例。
- 缩略图重新挂载时同步使用已记忆的宽高比构建第一帧，不在布局阶段之后等待异步图片解码回调改变宽度。
- 横向列表在向任一方向滚动时，列表项宽度不发生二次变化：已展示过并滑出可见区域的缩略图，滚回时宽度与滑出前一致。
- 向左滑动离开列表起点后，用户必须始终能够向右滑动返回；任何方向上的滚动不得出现跳回列表开头（闪回）、闪烁或滚动被抵消的现象。

### Scenario: 长剧照列表向左滑动后可正常向右回滑

Given 剧照列表有多张图片且均已加载展示
When 将列表向左滑动远离起点，再向右滑动返回
Then 回滑全程平稳无跳变，不闪回列表开头，滚动不被抵消

### Scenario: 滑出可见区域再滚回无二次宽度变化

Given 某缩略图已按图片实际宽高比显示后被滑出可见区域
When 该缩略图重新滚入可见区域
Then 其第一帧即以滑出前相同的宽高比构建，不再出现 16:9 占位到实际比例的二次变化

### Scenario: 同一 URL 宽度跨挂载一致

Given 同一张剧照（同一 URL）在会话内多次因滚动被销毁重建
When 观察每次重建后的缩略图宽度
Then 全部一致，与该 URL 解码出的实际宽高比记忆值相同

## 原有行为保持（承袭 movie-detail-stills 既有规格）

- 加载前按默认 16:9 占位；首次解码完成后按实际宽高比更新缩略图宽度；完整显示、不裁剪、不留空隙。
- 竖图与超宽图宽高比 clamp 在 [1.0, 21/9]；区块整体高度 164；横向列表保持懒构建结构。
- 点击打开 `ImageGalleryViewer` 并定位对应剧照；`Semantics`（button、label「查看剧照 N，共 M 张」）与 Key（`movie-detail-screenshot-N`）不变。

### Scenario: 自适应显示行为保持不变

Given 剧照图片尚未加载或刚加载完成
When 查看对应缩略图
Then 未加载时为 16:9 占位；加载完成后按实际宽高比完整显示，竖图/超宽图 clamp 在 [1.0, 21/9]

### Scenario: 点击与语义保持不变

Given 缩略图已按宽高比记忆机制显示
When 点击任一剧照缩略图或使用无障碍服务聚焦
Then 打开大图查看器并定位对应图片；语义标签与 Key 与修改前一致
