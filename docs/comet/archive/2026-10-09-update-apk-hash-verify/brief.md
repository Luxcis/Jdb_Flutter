# 目标

在线更新功能中，安装包下载完成后、调起系统安装器之前，对已下载的 APK 计算 SHA-256 并与 GitHub 发行版发布的哈希比对：一致才继续安装，不一致或无法校验时阻止安装，避免损坏或被篡改的安装包被拉起安装。

# 范围

- `GitHubReleaseAsset` 解析新增发行版资产的 `digest` 字段（格式 `sha256:<hex>`），该字段已随检查更新的 release JSON 返回。
- `UpdateInstaller` 新增哈希校验能力：计算本地已下载 APK 的 SHA-256（package:crypto），期望哈希优先取资产 `digest`，缺失时回退下载同名 `.sha256` 文件（CI 已随发行版上传，`sha256sum` 输出格式）解析首列为期望值。
- `UpdateDialog` 调整安装流程交互：下载完成后显示「安装」按钮；点击安装时执行校验并展示校验中状态；校验失败或无法校验时给出提示与重试入口。
- `profile_settings_screen` 的下载安装编排调整为：下载完成 → 等待用户点击「安装」→ 哈希校验 → 通过后调起 `OpenFilex`。
- 单元测试：哈希一致通过、不一致失败、`digest` 缺失回退 `.sha256` 文件、`.sha256` 内容解析、无法获取期望哈希、本地文件损坏；弹窗安装与校验状态机的 widget 测试。

# 非目标

- 不修改检查更新、版本比较、GitHub 代理、ABI 选择（`pickAsset`）等既有逻辑。
- 不修改发布流程：CI 已为每个 APK 上传 `.sha256` 文件，无需调整。
- 不做引导签名校验、Play Integrity 等更强的安装包验证（超出哈希一致性范围）。
- 不覆盖 iOS / 桌面端（本项目更新功能仅面向 Android）。

# 验收示例

- A1: 下载完成后进入待安装状态：下载进度完成后弹窗停在完成态并显示「安装」按钮；用户未点击「安装」前不调起系统安装器。
- A2: 校验通过安装：点击「安装」时计算已下载 APK 的实际 SHA-256，与期望哈希一致（无论期望值来自资产 `digest` 还是 `.sha256` 文件）时调起系统安装器，弹窗不出现失败提示。
- A3: 校验不一致阻止安装：实际 SHA-256 与期望哈希不一致时不调起系统安装器，删除已下载的损坏文件，弹窗显示「安装包校验失败，已阻止安装」并可重新下载。
- A4: 回退 `.sha256` 文件校验：资产 `digest` 缺失且同名 `.sha256` 文件可下载时，以该文件解析的期望哈希（取首列哈希、忽略 `sha256:` 前缀与十六进制大小写）完成校验，结果与使用 `digest` 时一致。
- A5: 无法校验时不安装：资产 `digest` 缺失且 `.sha256` 文件不可获取（下载失败或内容非法）时，不调起系统安装器并提示「无法校验安装包完整性」（fail-closed，不静默放行安装）。
- A6: 校验过程可见：点击「安装」后的校验期间弹窗显示「正在校验安装包完整性…」，同一时刻不重复触发校验；校验结束后仅有通过或失败两种可见结果。

# 约束与不变量

- 文案使用中文硬编码，主题遵循 Material 3（项目 RULES：无 l10n、无 haptics）。
- 不新增 pubspec 依赖：`crypto: ^3.0.6` 已存在，用它计算 SHA-256。
- 下载目录与文件路径不变：`<应用文档目录>/update/app-jade.apk`；下载进度回调签名不变。
- 检查更新入口、版本比较、资产选择与既有下载进度展示行为不变。
- 校验过程只读取已下载文件；仅 A3（校验不一致）允许删除该文件，其他路径不得移动、重命名或删除。

# 决策

- 期望哈希数据源：优先使用 release JSON 中资产自带的 `digest` 字段（检查更新时已获取，零额外网络请求）；缺失时回退下载 `<asset名>.sha256` 文件解析首列。
- 比对规则：忽略 `sha256:` 前缀与十六进制大小写差异；期望值格式非法（长度不为 64 的十六进制）视为无法校验。
- 校验算法固定 SHA-256，与 CI `sha256sum` 输出及 GitHub `digest` 一致。
- Q1 安装触发方式：采用手动「安装」按钮（选项 B）。依据：用户原话「下载完成后点击安装时校验」即明确下载与安装两步分开、校验挂在点击安装动作上；自动安装（选项 A）作为备选。未获用户逐项答复，将在最终 Shape 确认中呈现，用户可改选。
- Q2 校验失败处置：采用 fail-closed（选项 A）——校验不一致或无法校验均不调起安装器；不一致时删除损坏文件并允许重新下载，无法校验时保留文件（可能仅是网络原因），提示可重试。选项 C（无法校验仍安装）被排除：与目标「避免损坏或被篡改的安装包被拉起」冲突。同样在最终 Shape 确认中呈现。
- 本地 SHA-256 的计算时机属于实现选择，由 Agent 决定（下载流中同步计算或下载完成后读取文件计算），不改变任何用户可见结果。
