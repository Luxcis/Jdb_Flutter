# 目标

影片详情页顶部标题栏随滚动位置切换展示形态：页面处于顶部时标题栏加高并换行展示完整影片标题；用户向下滚动离开顶部后，标题栏收拢为单行，标题超出部分以省略号隐藏；回到页面顶部时恢复多行展示。

# 范围

- 仅调整影片详情页顶部标题栏（当前为 `Scaffold.appBar` 中固定单行省略的 `AppBar`）的展示形态与滚动联动。
- 标题文案仍取 `detail.title`；返回按钮、状态栏样式、页面背景色与主题保持一致。
- 详情页封面区、四个 Tab 内容、TabBar 固定行为和既有数据加载逻辑不变。

## 目录结构

### 新建

- lib/features/movie_detail/widgets/movie_detail_title_bar.dart — 承载可折叠标题栏组件：展开态多行完整标题、收起态单行省略标题，并负责标题所需高度测量。
- test/features/movie_detail/movie_detail_title_bar_test.dart — 覆盖顶部多行、滚动后单行省略、回到顶部恢复等形态切换的 widget 测试。

### 修改

- lib/features/movie_detail/screens/movie_detail_screen.dart — 移除既有单行 `AppBar`，改为使用新的标题栏组件（加载中/加载失败分支保持现状）。
- lib/features/movie_detail/widgets/basic_info_widgets.dart — `MovieDetailTabs` 的滚动头部加入标题栏，保持封面、TabBar 的既有先后顺序。
- test/features/movie_detail/movie_detail_screen_test.dart — 调整既有 `SliverPersistentHeader` 断言，并补充标题栏存在性与位置校验。

### 明确不建

- 不把折叠标题栏抽象到 `lib/core/widgets/` — 目前仅影片详情页需要，避免过早抽象。

# 非目标

- 不修改演员详情、资讯详情等其他页面的标题栏。
- 不调整详情页内容区（封面、信息卡、Tab 内容）的布局、交互与数据加载。
- 不新增文案、本地化、字体或第三方依赖。
- 不改动在线播放、预告片、收藏/短评等既有功能。

# 验收示例

- 页面处于顶部时，标题栏以多行展示完整影片标题，标题不被截断为单行。
- 用户向下滚动离开顶部后，标题栏收拢为单行，标题超出部分以省略号隐藏，返回按钮仍可点击返回。
- 用户滚动回到页面顶部后，标题栏恢复多行完整标题展示。
- 在「磁链下载」「短评」「相关清单」Tab 内向下滚动时，标题栏同样为单行收起状态并固定可见。
- 收起状态下标题栏固定在页面顶部，TabBar 固定在其下方，页面可继续滚动浏览内容。

# 约束与不变量

- 标题文案仍来自 `detail.title`，不新增或改写文案。
- 返回按钮行为、页面背景、状态栏图标亮度与 Material 3 主题保持一致。
- 标题样式沿用现有标题栏：`textTheme.titleLarge` 加粗，字号不因展开/收起而变化。
- 标题左内边距与既有 AppBar 标题对齐（返回按钮 56 + 间距 16），右内边距 16。
- 展开高度按标题实际行数计算；为避免极端超长标题占满屏幕，展开态高度上限为屏幕可用高度的 40%，仅此类极端标题才允许以省略号截断。
- 详情页加载中/加载失败状态保持现状。
- 不新增第三方依赖。

# 决策

- Q1 已确认：采用「随滚动连续折叠」。标题栏作为详情页滚动结构的一部分（`NestedScrollView` 的 header），展开高度变化由滚动距离直接驱动，不使用定时动画；滚动一开始标题即切为单行省略，滚回顶部连续恢复多行。
- 标题栏使用 `SliverAppBar(pinned: true)` 实现收起后固定在顶部，TabBar 固定在其下方。
- 展开态与收起态使用同一标题文案、同一字号与字重，仅行数、高度与省略状态不同。
- 标题栏背景取主题 `colorScheme.surface`，保证收起后封面等内容从标题栏下方滚过时标题仍清晰可读。
