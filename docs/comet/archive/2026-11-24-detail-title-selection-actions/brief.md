# 目标

影片详情页顶部标题栏中的影片标题支持长按进入文本选择态，弹出与评论正文完全一致的中文操作菜单「复制」「搜索」「全选」：复制把所选可见文本写入剪贴板；搜索以规范化后的所选可见文本为关键词 push 打开关键词搜索结果页 `/search/results?q=<关键词>`；全选选中标题全部可见文本。展开态（多行完整标题）与收起态（单行省略标题）均可选择，标题栏既有的折叠动画、高度测量、返回按钮、无障碍朗读与页面滚动不受影响。

# 范围

- 标题栏展开态与收起态两层标题都提供选择能力；选择范围只包含标题文本，不包含封面、番号、元数据、Tab 等其他元素。
- 操作菜单与评论区一致：「复制」「搜索」「全选」，中文硬编码。
- 复制：剪贴板内容等于当前所选可见文本；收起态单行省略或展开态被高度上限截断时，选区越过省略号则只使用省略号之前的可见前缀。
- 搜索：关键词先去除首尾空白、把内部换行与连续空白折叠为单个空格；随后关闭菜单并以 push 语义打开 `/search/results?q=<关键词>`；规范化后为空时不跳转。
- 标题栏不新增点击行为：未选中时点击标题无任何动作（不展开/收起、不跳转）。
- 评论区与标题栏共用同一选择组件：把评论正文现有的选择实现上提为 core 通用组件，评论正文的菜单、复制、搜索、展开/收起交互与既有测试保持不变。
- 标题栏随折叠进度重建，可见前缀在标题栏构建时计算一次并传入，不在滚动帧内重复做文本测量。

## 目录结构

### 新建

- lib/core/widgets/selectable_copy_search_text.dart — 从评论正文上提的通用可选择文本组件：长按选择、复制/搜索/全选菜单、关键词规范化、可见前缀截断；同时导出可见前缀计算函数 `visiblePrefixOf`，供评论区与标题栏共用。
- test/features/movie_detail/movie_detail_title_selection_test.dart — 标题选择组件测试：展开态菜单、复制、搜索跳转与关键词、收起态可见前缀、在标题上拖动仍滚动页面。

### 修改

- lib/features/movie_detail/widgets/movie_detail_title_bar.dart — 展开态与收起态标题改用通用可选择文本，按各自 `maxLines` 计算并传入可见前缀；折叠动画、高度测量、语义交替与返回按钮不变。
- lib/core/widgets/review/expandable_review_content.dart — 删除本地 `ReviewSelectableText` 与私有可见前缀函数，改用通用组件与共享函数，评论行为不变。
- test/core/widgets/review_selection_search_test.dart — 直接构造选择组件的一处测试改用通用组件的名称与路径。

### 不新建

- 独立的「标题选择」能力规格 — 标题选择是 `movie-detail-title-bar` 能力的扩展，菜单与关键词规则复用 `review-text-selection` 已确认的行为，不新增重复规格。

# 非目标

- 不为标题栏以外的详情页元素（封面、番号、元数据、类别、演员、剧照、Tab 文案）提供选择。
- 不新增分享、翻译、朗读等菜单动作；不改变评论区的菜单项与行为。
- 不改变标题栏的折叠动画、高度上限、字体、颜色、无障碍朗读策略与返回按钮。
- 不引入本地化框架或第三方依赖；不改动搜索结果页结构与搜索历史规则。

# 验收示例

- 长按展开态影片标题后进入选择态，并展示含「复制」「搜索」「全选」的操作菜单。
- 选中标题片段后点击「复制」，系统剪贴板内容与所选可见文本一致，菜单关闭。
- 选中标题片段后点击「搜索」，菜单关闭并以规范化关键词（去首尾空白、内部连续空白折叠为单空格）push 进入关键词搜索结果页，URL 的 q 与结果页搜索框显示的关键词一致。
- 收起态单行省略标题（以及展开态被截断的极端超长标题）长按全选后，复制与搜索仅使用省略号之前的可见前缀文本。
- 在标题上垂直拖动仍由页面滚动接管；标题栏折叠/展开高度、返回按钮、大字号不溢出、加载/失败态等既有行为不变。
- 评论区正文的选择菜单、复制、搜索与展开/收起交互在共用组件重构后保持不变。

# 约束与不变量

- 文案中文硬编码，遵循 RULES，不引入本地化。
- 选择组件位于 `lib/core/`，不依赖 features；跳转只用 `AppRoutes.searchResults` 与 `q` 查询参数，由 `Uri` 构造保证编码。
- 可见前缀测量与渲染使用同一 `TextScaler`、`TextDirection` 与最大宽度；展开态仅在 `expandedMaxLines` 小于实际行数时计算前缀。
- 标题栏是滚动头部：可见前缀只在标题栏构建时计算，滚动帧内不新增文本测量。
- 选择能力不得抢占页面滚动：触摸垂直拖动仍由滚动容器接管，长按才进入选择态。

# 决策

- 选择同时作用于展开态与收起态两层标题：收起态是滚动后的主要可见形态，只做展开态会造成行为不一致。
- 复用评论区实现而不是在标题栏另写一份：把 `ReviewSelectableText` 上提为 `lib/core/widgets/selectable_copy_search_text.dart` 的通用组件，菜单项、关键词规范化与可见前缀规则因此完全一致。
- 截断态沿用评论区的「可见前缀」规则（复制/搜索不含省略号之后的隐藏文本），而不是复制完整标题：与「同评论区」一致，避免同一菜单在不同位置给出不同的文本。
- 菜单顺序沿用「复制」「搜索」「全选」。
- 点击标题不新增动作，保持既有行为（标题栏只响应滚动）。
