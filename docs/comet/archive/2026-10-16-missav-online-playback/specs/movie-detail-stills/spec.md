# 影片详情页剧照缩略图（正片 / 预告片 / 剧照区）——滚动稳定性与播放入口

## 概述

影片详情页「正片 / 预告片 / 剧照」区（`MovieScreenshotSection`）横向展示播放入口与剧照缩略图：最前为「正片」在线播放入口（行为见 `missav-playback` 规格），其次为「预告片」播放入口（`previewVideoUrl` 非空时），其后为剧照缩略图。本规格包含两部分：播放入口层的组成与标识；剧照缩略图在 `detail-still-autoscale` 的「按实际宽高比自适应」能力之上的滚动稳定性要求（剧照列表长度不限，横向滚动在向前与回退方向上都必须稳定，不允许因缩略图重新挂载而出现闪回）。

## 播放入口（正片 / 预告片）

- 区块标题为「正片 / 预告片 / 剧照」。
- 区块恒定显示：不依赖影片是否有预告片或剧照（无预告片、无剧照的影片也显示该区块）。
- 横向列表最前两项为播放入口，顺序固定为「正片」在前、「预告片」在后：
  - 「正片」入口：16:9 卡片，封面使用影片封面（`MovieCoverImage` cover variant、`BoxFit.cover`），中央为圆形半透明底的播放图标，卡片上有可见文本标识「正片」；语义 label「播放《影片标题》正片」，Key `movie-detail-online`；点击进入在线播放页（解析、播放、失败处理见 `missav-playback` 规格）。
  - 「预告片」入口：仅当 `previewVideoUrl` 非空时出现；16:9 卡片，封面使用影片封面（与现状一致），中央为播放图标，卡片上有可见文本标识「预告片」；语义 label「播放《影片标题》预告片」，Key `movie-detail-preview`；点击进入现有预告片播放页。
- 两个入口的文本标识为卡片上的可见文本（颜色可读、不依赖无障碍语义），浅色/深色主题下均可读。
- 正片入口不因解析或播放失败而隐藏或禁用：失败反馈发生在播放页内，入口保持可用。

### Scenario: 播放入口顺序与文本标识

Given 影片详情页已加载
When 查看「正片 / 预告片 / 剧照」区横向列表
Then 最前依次为带「正片」文本标识的正片入口与带「预告片」文本标识的预告片入口，其后为剧照缩略图

### Scenario: 无预告片与剧照时区块仍显示

Given 影片没有预告片也没有剧照
When 查看详情页
Then 区块仍显示且包含正片入口；预告片入口不出现；无空指针或布局异常

### Scenario: 正片入口点击进入在线播放

Given 正片入口显示
When 点击正片入口
Then 进入在线播放页（解析、播放与失败处理见 missav-playback 规格）

### Scenario: 预告片入口点击行为不变

Given 影片有预告片（`previewVideoUrl` 非空）
When 点击预告片入口
Then 进入现有预告片播放页；行为、语义 label 与 Key 与修改前一致

## 滚动稳定性

- 剧照缩略图的宽高比以 URL 为键被记忆：某 URL 的图片真实比例一经解码，与会话期内所有该 URL 的缩略图实例共享，包括懒构建列表中被销毁又重新挂载的实例。
- 缩略图重新挂载时同步使用已记忆的宽高比构建第一帧，不在布局阶段之后等待异步图片解码回调改变宽度。
- 横向列表在向任一方向滚动时，列表项宽度不发生二次变化：已展示过并滑出可见区域的缩略图，滚回时宽度与滑出前一致。
- 向左滑动离开列表起点后，用户必须始终能够向右滑动返回；任何方向上的滚动不得出现跳回列表开头（闪回）、闪烁或滚动被抵消的现象。

### Scenario: 长剧照列表向左滑动后可正常向右回滑

Given 剧照列表有多张图片且均已加载展示
When 将列表向左滑动远离起点，再向右滑动返回
Then 回滑全程平稳无跳变，不闪回列表开头，滚动不被抵消

### Scenario: 滑出可见区域再滚回无二次宽度变化

Given 某缩略图已按图片实际宽高比显示后被滑出可见区域
When 该缩略图重新滚入可见区域
Then 其第一帧即以滑出前相同的宽高比构建，不再出现 16:9 占位到实际比例的二次变化

### Scenario: 同一 URL 宽度跨挂载一致

Given 同一张剧照（同一 URL）在会话内多次因滚动被销毁重建
When 观察每次重建后的缩略图宽度
Then 全部一致，与该 URL 解码出的实际宽高比记忆值相同

## 剧照原有行为保持（承袭 movie-detail-stills 既有规格）

- 加载前按默认 16:9 占位；首次解码完成后按实际宽高比更新缩略图宽度；完整显示、不裁剪、不留空隙。
- 竖图与超宽图宽高比 clamp 在 [1.0, 21/9]；区块整体高度 164；横向列表保持懒构建结构。
- 点击打开 `ImageGalleryViewer` 并定位对应剧照；`Semantics`（button、label「查看剧照 N，共 M 张」）与 Key（`movie-detail-screenshot-N`）不变。

### Scenario: 自适应显示行为保持不变

Given 剧照图片尚未加载或刚加载完成
When 查看对应缩略图
Then 未加载时为 16:9 占位；加载完成后按实际宽高比完整显示，竖图/超宽图 clamp 在 [1.0, 21/9]

### Scenario: 点击与语义保持不变

Given 缩略图已按宽高比记忆机制显示
When 点击任一剧照缩略图或使用无障碍服务聚焦
Then 打开大图查看器并定位对应图片；语义标签与 Key 与修改前一致
