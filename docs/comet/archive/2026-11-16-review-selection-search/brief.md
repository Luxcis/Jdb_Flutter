# 目标

评论卡片正文长按选中文字后的悬浮操作菜单新增「搜索」项：点击后以当前选中文本（规范化后）作为关键词，跳转到关键词搜索结果页 `/search/results?q=<关键词>` 并展示对应搜索结果、记录搜索历史；返回时可回到原页面。

# 范围

- 评论正文选择菜单（当前为「复制」「全选」）新增「搜索」项；「复制」「全选」行为保持不变。
- 「搜索」的关键词取当前选中文本：去除首尾空白，内部换行与连续空白折叠为单个空格。
- 折叠态正文（超过 5 行、省略号截断）下，若选区覆盖省略号之后的隐藏文本，则与复制一致，仅使用省略号之前的可见前缀作为关键词。
- 点击「搜索」后关闭操作菜单，并压栈打开关键词搜索结果页 `/search/results?q=<关键词>`；返回后回到评论所在页面，评论展开/收起状态保持原样。
- 规范化后关键词为空时（选中内容全为空白）不跳转，仅关闭操作菜单。
- 由评论菜单发起的关键词搜索写入搜索历史（搜索首页「最近搜索」可见）；实现为关键词搜索结果页首次进入时记录 URL 中的关键词，使任何进入结果页的路径都保持一致，且重复保存幂等。
- 影片详情页短评列表与「看短评」页共用同一评论卡片组件，两处行为一致。
- 搜索结果页的页面结构、分页、Tab、页内重新搜索交互保持不变。

## 目录结构

### 修改

- lib/core/widgets/review/expandable_review_content.dart — `ReviewSelectableText` 的选择操作菜单新增「搜索」项；抽取选区文本规范化（可见前缀截断、空白处理）并在点击后导航至关键词搜索结果页。
- lib/features/search/screens/search_results_screen.dart — 首次进入结果页时把 URL 中的关键词写入搜索历史（幂等，复用 `SearchHistoryStore`），不改动页内提交逻辑。
- test/core/widgets/review_selection_search_test.dart — 新增 widget 测试：菜单项、关键词规范化与可见前缀、空关键词、返回后页面状态，以及经真实结果页验证搜索历史写入。

# 非目标

- 不为评论卡片其它文本（作者名、日期、影片信息区等）提供搜索或选择。
- 不改动资讯正文、设置页等其它可选择文本处的选择菜单。
- 不新增分享、翻译等其它菜单动作，不改变「复制」「全选」的选取范围规则与剪贴板行为。
- 不改造搜索结果页的页面结构、分页/Tab 行为与页内重新搜索逻辑；不为该入口新增路由查询参数。

# 验收示例

- 长按评论正文进入选择态后，操作菜单同时展示「复制」「搜索」「全选」。
- 选中评论正文片段后点击「搜索」，进入关键词搜索结果页，URL 关键词与选中文本一致（去除首尾空白、内部连续空白折叠为单个空格），页面顶部搜索框显示该关键词。
- 折叠态正文中包含省略号之后的隐藏文本时，点击「搜索」使用的关键词仅为省略号之前的可见前缀文本。
- 选中内容规范化后为空时点击「搜索」，不打开搜索结果页，操作菜单关闭。
- 从搜索结果页返回后回到原评论所在页面，评论展开/收起状态与页面滚动位置保持原样。
- 评论卡片的复制、全选、展开/收起、点赞、影片信息区跳转等既有行为不受影响。
- 影片详情页短评列表与「看短评」页的评论正文菜单均提供「搜索」并执行相同跳转。
- 由评论菜单跳转进入搜索结果页后，该关键词出现在搜索历史中（搜索首页「最近搜索」可见）。

# 约束与不变量

- 文案使用中文硬编码，遵循项目 RULES，不引入本地化框架。
- 菜单沿用现有 `AdaptiveTextSelectionToolbar.buttonItems` 结构，不引入新的菜单组件或第三方依赖。
- 跳转使用既有路由常量 `AppRoutes.searchResults` 与查询参数 `q`，由 `Uri` 构造保证关键词正确编码；采用 push 语义，返回栈可回到评论所在页面。
- 保持 core 不依赖 features 的架构边界：评论组件只负责规范化关键词与跳转，不直接读写搜索业务服务；搜索历史由搜索结果页写入。
- 折叠态可见前缀的判定与复制保持一致，使用 `ExpandableReviewContent` 已计算并传入的 `visiblePrefix`。
- 搜索历史的去重、置顶与最多 20 条规则沿用 `SearchHistoryStore` 现状。

# 决策

- Q1 已确认：由评论菜单发起的搜索写入搜索历史（搜索首页「最近搜索」可见）。
- 历史写入放在关键词搜索结果页首次进入时执行，而不是评论组件里：避免 core 依赖 features 搜索服务，也不新增路由参数；页内提交路径原本就会保存，重复保存幂等。
- 「搜索」在菜单中的位置为「复制」之后、「全选」之前。
- 选中文本的规范化规则：折叠态先截断为可见前缀，再去除首尾空白并把内部换行/连续空白折叠为单个空格。
- 菜单点击后先关闭操作菜单再执行跳转，避免悬浮菜单残留在新页面上方。
