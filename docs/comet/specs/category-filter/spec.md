# 类别页筛选（category-filter）完整目标规格

## 概述

类别页（`CategoriesPage`）提供五个内容 Tab（有码/无码/欧美/FC2/动漫），每个 Tab 拥有独立的
`CategoryTabController` 与影片网格（`MovieGridView`）；AppBar 的筛选按钮打开底部筛选面板
（`CategoryFilterSheet`，模态 bottom sheet，高度约为屏幕 2/3），面板头部固定显示排序方式菜单与
发布日期升降序开关，下方为按分组的筛选标签列表（FilterChip）。

## 筛选数据与即时刷新

- 面板内容来自当前 Tab 的标签接口（`getTags(type)`）：加载中显示加载状态，失败显示重试入口，成功为空显示“暂无筛选项”。
- 标签语义：main/year/duration/month 固定段为单选（可取消），动态题材分组为多选。
- 任一筛选条件（标签、排序方式、升降序）变化立即触发当前 Tab 影片网格自动刷新（`reloadWith(_fetchPage, preserveItems: true)`），旧列表保留至新首页数据到达。
- 筛选状态变化通过 `CategoryTabController`（ChangeNotifier）通知 UI。

## 筛选触发的滚动置顶

- 任一筛选条件变化触发影片网格 reload 时，当前 Tab 的影片网格自动滚动到顶部（滚动偏移归零）。
- 滚动置顶在触发刷新的帧末执行，不等待刷新结果到达。
- 滚动置顶仅作用于发生筛选变化的当前 Tab 网格，其他 Tab 网格的滚动位置不受影响。
- `MovieGridView` 以可选参数提供该能力且默认关闭；下拉刷新、加载更多、错误重试等其余刷新路径行为保持不变。

## 筛选面板滚动位置记忆

- 筛选列表（ListView）的滚动位置在面板收起后由类别页按 Tab 独立保留。
- 再次展开面板时，筛选列表恢复到该 Tab 收起前的滚动位置。
- 面板打开时若标签仍在加载、失败或为空则不显示列表，列表出现后按保存的偏移恢复。
- 位置记忆生命周期为页面存活期间（内存内），不跨应用重启持久化。

## 非目标

- 不改变其他页面复用 `MovieGridView` 的滚动行为（置顶能力默认关闭）。
- 不改变下拉刷新、加载更多、错误重试的现有行为。
- 不改变筛选条件即时生效（自动刷新、保留旧数据直到新数据到达）的现有逻辑。
- 不改变切换 Tab 时影片网格滚动位置独立保留的既有行为。
- 不做筛选面板滚动位置的跨会话持久化。

## 场景

### Scenario: 切换标签触发刷新后网格回到顶部

Given 类别页当前 Tab 影片网格已向下滚动到非零偏移
When 打开筛选面板并点选任一标签触发自动刷新
Then 当前 Tab 影片网格滚动偏移回到 0

### Scenario: 切换排序或升降序触发刷新后网格回到顶部

Given 类别页当前 Tab 影片网格已向下滚动到非零偏移
When 在筛选面板切换排序方式或发布日期升降序
Then 当前 Tab 影片网格滚动偏移回到 0

### Scenario: 其他 Tab 网格滚动位置不受筛选置顶影响

Given Tab 0 网格滚动到非零偏移，Tab 1 网格滚动到另一非零偏移
When 在 Tab 0 变更筛选条件触发刷新
Then Tab 0 网格偏移回到 0，切到 Tab 1 后其网格偏移保持不变

### Scenario: 筛选面板收起再展开恢复滚动位置

Given 筛选面板筛选列表已向下滚动到非零偏移
When 收起面板后再次展开
Then 筛选列表滚动偏移恢复到收起前的值

### Scenario: 各 Tab 筛选面板滚动位置相互独立

Given Tab 0 筛选列表滚动到偏移 X 后收起
When 切到 Tab 1 展开筛选并将列表滚动到偏移 Y 后收起，再切回 Tab 0 展开
Then Tab 0 筛选列表恢复偏移 X
