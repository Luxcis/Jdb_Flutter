# 评论正文文本选择（review-text-selection）完整目标规格

## 概述

评论卡片（`ReviewTile`，`lib/core/widgets/review_tile.dart`）是影片详情页短评列表
（`MovieReviewList`）与"看短评"页（`ReviewsPage`）共用的评论展示组件。本能力为评论正文
（`_ExpandableReviewContent` 渲染的 `Review.content`）增加文本选择能力：长按进入选择态并展示
操作菜单，可选取并复制评论文本，也可用所选文本作为关键词搜索；同时保留既有"点击正文展开/收起"交互。

## 选择能力

- 长按评论正文：选中长按处的词语并显示选择手柄，同时展示文本选择操作菜单。
- 操作菜单提供"复制""搜索"与"全选"，菜单标签使用中文硬编码（遵循项目文案约定）。
- 点击菜单"复制"后，系统剪贴板内容与当前所选文本一致，菜单关闭。
- 拖动选择手柄可调整选择范围；"全选"选中正文全部可见文本。
- 选择能力仅作用于评论正文；作者名、评分、影片信息区、点赞行、日期等不可选择。
- 正文不超过 5 行（无展开/收起控制）与超过 5 行折叠态（省略号截断）两种形态下均可长按选择其可见文本。

## 搜索动作

- "搜索"使用当前选中文本作为关键词：先去除首尾空白，再把内部换行与连续空白折叠为单个空格。
- 折叠态正文的选区若覆盖省略号之后的隐藏文本，与"复制"一致，仅使用省略号之前的可见前缀作为关键词。
- 点击"搜索"后先关闭操作菜单，再以 push 语义打开关键词搜索结果页
  `/search/results?q=<关键词>`（关键词按 URI 查询参数编码）；返回后回到评论所在页面。
- 规范化后关键词为空（选区全为空白）时，不打开搜索结果页，仅关闭操作菜单。
- 搜索结果页在首次进入时把关键词写入搜索历史，因此由评论菜单发起的搜索同样出现在搜索首页的
  "最近搜索"中；去重、置顶与最多 20 条规则沿用 `SearchHistoryStore` 现状。
- 搜索动作不改变选择态之外的任何卡片状态：展开/收起状态、点赞状态与页面滚动位置保持不变。

## 点击交互与选择的共存

- 未处于选择态（无选中文字）时，点击超过 5 行的折叠/展开正文仍触发展开/收起，行为与现状一致。
- 已选中文字时，点击正文仅清除选择并关闭操作菜单，展开/收起状态不变化。
- "展开/收起"按钮行为保持不变，与正文点击互不影响。

## 不变行为

- 点赞流程（含未登录提示与登录跳转）、影片信息区跳转、日期展示等既有行为不变。
- 列表垂直滑动仍由滚动容器接管，长按才进入选择态；分页加载、下拉刷新等不受影响。

## 非目标

- 不支持复制或搜索正文以外的卡片元素文本。
- 不新增翻译、分享等扩展菜单动作。
- 不引入 flutter_localizations 或 .arb 本地化框架。

## 场景

### Scenario: 长按评论正文进入选择态并展示操作菜单

Given 评论卡片展示非空评论正文
When 长按评论正文
Then 正文进入选择态（出现选择手柄）并展示含"复制""搜索""全选"的操作菜单

验收：A1

### Scenario: 复制所选评论文本

Given 已通过长按选中部分评论文本并展示操作菜单
When 点击菜单中的"复制"
Then 系统剪贴板内容与所选文本一致，菜单关闭

验收：A6

### Scenario: 折叠态正文可长按选择并复制

Given 评论正文超过 5 行处于折叠显示（省略号截断）
When 长按正文可见部分并点击"复制"
Then 进入选择态且剪贴板内容与所选可见文本一致

验收：A6

### Scenario: 短评正文长按选择并复制

Given 评论正文不超过 5 行（无展开/收起控制）
When 长按正文并点击"复制"
Then 剪贴板内容与所选文本一致

验收：A6

### Scenario: 未选择时点击正文仍展开收起

Given 评论正文超过 5 行处于折叠显示且当前无选中文字
When 点击正文，待展开后再次点击正文
Then 第一次点击后正文展开，第二次点击后正文收起

验收：A6

### Scenario: 选中时点击正文仅清除选择

Given 评论正文已有选中文字并展示操作菜单
When 点击正文
Then 选择被清除、菜单关闭，展开/收起状态不变化

验收：A6

### Scenario: 全选复制全部可见文本

Given 评论正文超过 5 行处于折叠显示
When 长按正文进入选择态后点击"全选"并点击"复制"
Then 剪贴板内容与折叠态正文全部可见文本一致

验收：A6

### Scenario: 搜索所选评论文本

Given 评论正文已有选中文字并展示操作菜单
When 点击菜单中的"搜索"
Then 操作菜单关闭，并进入关键词搜索结果页，URL 的 `q` 与选中文本规范化后的结果一致（去除首尾空白、内部换行与连续空白折叠为单个空格）
And 结果页顶部搜索框显示该关键词

验收：A2

### Scenario: 折叠态搜索使用可见前缀

Given 评论正文超过 5 行处于折叠显示（省略号截断且存在隐藏文本）
When 长按正文进入选择态后点击"全选"再点击"搜索"
Then 跳转使用的关键词仅为省略号之前的可见前缀文本，不包含隐藏文本

验收：A3

### Scenario: 空关键词不跳转

Given 评论正文仅含空白字符且已选中该片段并展示操作菜单
When 点击菜单中的"搜索"
Then 不打开搜索结果页，操作菜单关闭，仍停留在评论所在页面

验收：A4

### Scenario: 从搜索结果页返回保留原页面状态

Given 评论正文超过 5 行且已展开（或折叠），并通过菜单"搜索"进入结果页
When 从搜索结果页返回
Then 回到原评论所在页面，评论展开/收起状态与页面滚动位置保持进入搜索前的状态

验收：A5

### Scenario: 两处评论列表行为一致

Given 影片详情页短评列表与"看短评"页均使用评论卡片展示评论
When 在任一页面对评论正文长按并点击"搜索"
Then 均以所选文本为关键词进入搜索结果页，且菜单交互一致

验收：A7

### Scenario: 既有交互不受影响

Given 评论卡片展示影片信息区、点赞行与展开/收起按钮
When 点击影片信息区、点击点赞、点击展开/收起按钮
Then 各既有行为保持不变，选择菜单不出现

验收：A6
