# 预告片播放操作层规格

## 概述

预告片播放页（`MoviePreviewScreen`）的播放操作层由项目自管理的自定义组件实现，不使用 media_kit 内置的 `MaterialVideoControls`。操作层包含顶部标题栏（返回按钮 + 标题）与底部操作栏（播放/暂停按钮、进度条、当前位置与时长），两者由同一个显隐状态机驱动，始终同步显示、同步隐藏。

操作层在视频画面之上提供以下手势：

- 单击：切换操作层显隐。
- 双击：播放 ↔ 暂停切换。
- 长按：2 倍速播放，松开恢复原速。
- 左半区垂直滑动：调节屏幕亮度。
- 右半区垂直滑动：调节系统媒体音量。
- 水平滑动：按拖动距离快进/快退。

## 显隐状态机

- 操作层可见性由单一状态源（一个通知器/计时器组合）驱动；顶部标题栏与底部操作栏只读取该状态，不各自维护计时器。
- 进入播放态后操作层默认可见，并启动自动隐藏计时。
- 可见状态下发生任意操作层交互（按钮点击、进度条拖动、手势）时重置自动隐藏计时。
- 自动隐藏时长为 3 秒：持续播放（`isPlaying` 且非缓冲、未完成、无错误）且无交互满 3 秒后，顶部标题栏与底部操作栏同时隐藏。
- 暂停、缓冲、播放完成或出错时，操作层保持可见，自动隐藏计时不生效。
- 隐藏状态下，顶部标题栏与底部操作栏均不响应指针事件、不参与语义树。

### Scenario: 单击切换顶部标题栏与底部操作栏同步显隐

Given 预告片正在播放且操作层处于隐藏状态
When 单击播放画面
Then 顶部标题栏与底部操作栏同时显示；再次单击后两者同时隐藏，任何时刻不存在只显示其一的状态

### Scenario: 播放中自动隐藏、暂停时保持显示

Given 操作层处于可见状态且正在持续播放
When 约 3 秒内没有任何交互
Then 顶部标题栏与底部操作栏同时自动隐藏

Given 操作层处于可见状态
When 播放进入暂停、缓冲、完成或出错状态
Then 操作层保持显示，不自动隐藏

## 底部操作栏

- 底部操作栏包含：播放/暂停按钮、可拖动进度条、当前位置与总时长文本。
- 进度条拖动时实时预览目标位置，松开后 seek 到该位置。
- 不提供全屏按钮（页面已强制横屏）。
- 播放完成时（`isCompleted`）播放按钮显示为重新播放语义；点击后从头播放。

## 手势

### 手势判定

- 单击与双击共存：单击在双击判定窗口（约 300ms）结束后未等到第二次按下才生效。
- 同一触摸序列只触发一类手势：按下后首段有效位移的方向判定为垂直滑或水平滑；判定后该序列不再触发其他手势。
- 长按与滑动手势互斥：长按成立前发生有效位移则取消长按；滑动中不触发长按倍速。
- 手势热区避开屏幕边缘安全距离（约 16dp），不与系统返回手势冲突。

### 长按 2 倍速

- 播放中长按画面任意位置，调用播放适配器将倍速设为 2.0，并显示倍速指示（如“2x”）。
- 手指松开（或触摸取消）后立即恢复原速（1.0），倍速指示消失。
- 倍速状态只存在于长按期间：页面退出、会话清理、播放完成或出错时不得残留 2 倍速。

### Scenario: 长按 2 倍速、松开恢复

Given 预告片正在以 1 倍速播放
When 长按播放画面不移动
Then 播放速度变为 2 倍并显示倍速指示

Given 正处于长按 2 倍速状态
When 松开手指
Then 播放速度立即恢复 1 倍，倍速指示消失

### 垂直滑动：亮度与音量

- 按下点位于屏幕左半区时，垂直滑动调节屏幕亮度；位于右半区时，调节系统媒体音量。
- 向上滑动增大、向下滑动减小；数值 clamp 在 [0.0, 1.0]。
- 滑动过程中实时显示指示器：亮度/音量图标 + 当前百分比；指示器在滑动结束约 1 秒后（或下一次其他手势开始时）消失。
- 屏幕亮度调节仅作用于本页面会话：进入播放页时读取当前系统亮度作为起点，退出播放页时恢复系统亮度。
- 系统音量调节直接作用于系统媒体音量，退出播放页后不回退。
- 亮度/音量通道调用失败只记录日志，不影响播放与操作层显隐。

### Scenario: 左半区垂直滑动调节亮度并实时显示

Given 预告片正在播放
When 在屏幕左半区向上或向下滑动
Then 屏幕亮度随之增大或减小，并实时显示当前亮度图标与百分比

### Scenario: 右半区垂直滑动调节音量并实时显示

Given 预告片正在播放
When 在屏幕右半区向上或向下滑动
Then 系统媒体音量随之增大或减小，并实时显示当前音量图标与百分比

### 水平滑动：快进快退

- 播放画面上水平滑动时，从按下时刻的播放位置出发，按拖动距离换算 seek 偏移：满宽拖动映射固定 seek 窗口（约 90 秒），实际偏移按拖动距离比例换算。
- 目标位置 clamp 在 `[0, duration]`；滑动过程中实时显示指示器（目标位置与偏移量，如 “01:23 / +15s”）。
- 松开后 seek 到目标位置并停留；指示器随后消失。
- 播放未完成初始化或时长未知（`duration <= 0`）时，水平滑动不产生 seek。

### Scenario: 水平滑动快进快退并实时显示目标位置

Given 预告片正在播放且总时长已知
When 在播放画面上向右或向左滑动
Then 滑动过程中实时显示目标位置与偏移量，松开后播放停留在 clamp 后的目标位置

### 双击播放/暂停

- 双击播放画面在播放与暂停之间切换，与现有 `MoviePreviewDoubleTapDetector` 行为一致。
- 播放完成时双击（或点击播放按钮）从头重新播放。
- 不再存在 media_kit 内置的双击快退/快进。

### Scenario: 双击切换播放暂停

Given 预告片正在播放
When 双击播放画面
Then 播放暂停；再次双击恢复播放

## 播放适配器扩展

- `MoviePreviewPlayback` 接口增加倍速设置能力（如 `Future<void> setRate(double rate)`）。
- `MediaKitMoviePreviewPlayback` 将其映射到 media_kit 的 `Player.setRate`。
- `buildView()` 使用 `NoVideoControls`，操作层完全由项目组件渲染。

## 非播放状态

- 加载中与播放失败页面保持现有行为：顶部标题栏可见、可返回；不显示底部操作栏与任何手势指示器，手势层不生效。
- 剧照区、详情页入口与路由行为保持不变。

### Scenario: 加载与错误页行为保持不变

Given 播放尚未初始化成功或播放出错
When 查看页面
Then 只显示顶部标题栏（与加载/错误内容），不显示底部操作栏，亮度/音量/seek/倍速手势均不生效
