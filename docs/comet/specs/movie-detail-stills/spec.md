# 影片详情页剧照缩略图（预告片 / 剧照区）

## 概述

影片详情页「基本信息」Tab 的「预告片 / 剧照」区（`MovieScreenshotSection`）横向展示预告片封面缩略图与剧照缩略图。本规格描述剧照缩略图按图片实际宽高比自适应缩放的完整行为。

## 区域布局

- 区块整体高度保持 164，由标题行（「预告片 / 剧照」+「共 N 张」尾注）与固定高度横向列表组成。
- 第一个格子（存在预告片时）为预告片封面缩略图，保持现有 16:9 显示方式，不属于剧照缩略图行为。
- 剧照缩略图统一高度（与横向列表内容区高度一致），宽度按各自图片宽高比计算：`宽度 = 高度 × clamp(图片宽高比, 1.0, 21/9)`。
- 图片未加载完成时使用默认宽高比 16/9 占位，即与修改前相同的格子尺寸。

## 剧照缩略图显示行为

- 剧照图片完整显示于缩略图内：既不被裁剪（不使用 cover 填充裁切），也不出现空隙填充（不使用 contain 留边）。
- 同一排中不同比例的剧照缩略图宽度各不相同，横向滚动行为保持流畅，任何情况下不产生布局溢出异常。
- 图片加载完成后按实际宽高比更新缩略图宽度；宽高比来源为图片流返回的真实图像尺寸。

### Scenario: 剧照缩略图按实际比例完整显示

Given 影片详情页「预告片 / 剧照」区存在剧照
When 某剧照图片加载完成
Then 该缩略图按图片实际宽高比缩放显示完整图片，不被裁剪，也没有空隙填充

### Scenario: 缩略图高度统一且横向滚动正常

Given 同一排中存在多张不同宽高比的剧照且已加载完成
When 浏览「预告片 / 剧照」横向列表
Then 所有剧照缩略图高度一致、宽度各自按实际比例自适应，横向滚动正常且无溢出

### Scenario: 未加载时按默认比例占位

Given 剧照图片尚未加载完成
When 查看「预告片 / 剧照」区
Then 该剧照缩略图按默认 16:9 占位显示，加载完成后切换为实际宽高比

### Scenario: 极端比例受保护

Given 某剧照为竖图或超宽图
When 该图片加载完成
Then 缩略图宽高比被限制在 [1.0, 21/9] 范围内，布局不溢出

## 交互与可访问性（保持不变）

- 点击剧照缩略图打开全屏大图查看器 `ImageGalleryViewer`，并定位到对应剧照。
- 剧照缩略图保留 `Semantics`（button，label「查看剧照 N，共 M 张」）与稳定 Key（`movie-detail-screenshot-N`）。
- 图片加载、缓存、解密与模糊设置沿用 `CachedImage` 现有逻辑，本规格不改变其公共行为。

### Scenario: 交互与语义保持不变

Given 剧照缩略图已按新方式自适应显示
When 点击任一剧照缩略图或使用无障碍服务聚焦
Then 仍打开大图查看器并定位对应图片，语义标签与 Key 与修改前一致
