# Capability: movie-detail-title-bar（影片详情标题栏）

本能力描述影片详情页顶部标题栏在所有状态下的完整行为：页面顶部时以多行展示完整标题、向下滚动后收拢为单行省略、折叠过程随滚动连续进行，以及固定可见、返回按钮与可访问性等不变量。文案与主题遵循项目 RULES（中文硬编码、Material 3）。

## 结构位置

- 标题栏是详情页 `NestedScrollView` 滚动头部的第一个 sliver，位于封面区（`MovieDetailHero`）之上、固定 TabBar 之前。
- 标题栏使用 `SliverAppBar(pinned: true)`：收起后固定在页面顶部，TabBar 固定在其下方。
- 背景取主题 `colorScheme.surface`，与页面背景一致，保证收起后封面等内容从标题栏下方滚过时标题仍清晰可读。
- 标题文案仍来自 `detail.title`，不新增或改写文案；返回按钮由 `SliverAppBar` 自动提供，行为与改动前的 AppBar 一致。
- 状态栏区域由标题栏自身处理（`primary: true`），状态栏图标亮度沿用主题 `AppBarTheme.systemOverlayStyle`。

## 展开态（页面处于顶部）

- 页面滚动位置为 0 时，标题栏处于展开态。
- 展开高度按标题实际换行行数计算：在 `textTheme.titleLarge` 加粗样式、左右内边距（左 72、右 16）下测量完整标题所需高度，加上底部 14、顶部 8 的留白，且不小于 `kToolbarHeight`。
- 标题以多行展示完整文本，不截断为单行；仅当展开高度超过屏幕可用高度 40% 的极端超长标题，才按可容纳行数以省略号截断。
- 标题底部对齐，左内边距与收起态一致；返回按钮位于标题栏左上角。

### Scenario: 页面处于顶部时展示多行完整标题

Given 影片标题长度需要两行或以上才能完整显示
When 用户打开影片详情页且未滚动
Then 标题栏以多行展示完整标题，标题不出现省略号，标题栏高度大于单行高度

验收：A1

### Scenario: 极端超长标题按可用高度截断

Given 影片标题在展开态所需高度超过屏幕可用高度的 40%
When 详情页处于顶部
Then 标题栏高度不超过屏幕可用高度的 40%，标题按可容纳行数以省略号截断，页面不出现布局溢出

## 收起态（用户向下滚动）

- 用户向下滚动时，标题栏高度随滚动距离连续收缩，直至 `kToolbarHeight`（加状态栏内边距）。
- 标题随折叠进度做交叉淡入淡出：多行完整标题在折叠前半程淡出，单行省略标题在折叠后半程淡入；动画进度完全由滚动距离决定，不使用定时器。
- 完全收起后只保留单行标题，超出部分以省略号隐藏；继续在任意 Tab 内容中滚动都不会改变其单行形态。
- 收起过程中标题保持底部对齐，左内边距与展开态一致；标题字号、字重、颜色保持不变。
- 向上滚动时上述过程反向进行，标题与高度随滚动距离连续恢复。

### Scenario: 向下滚动后标题收拢为单行省略

Given 详情页处于页面顶部且标题栏为多行展开态
When 用户向下滚动使标题栏离开顶部
Then 多行标题随折叠进度淡出、单行标题淡入，标题栏高度随滚动收缩到单行高度，返回按钮仍可点击返回

验收：A2

### Scenario: 折叠过程中标题随滚动距离平滑过渡

Given 详情页处于页面顶部且标题栏为多行展开态
When 用户向下滚动到折叠进度的中间位置
Then 多行标题与单行标题同时存在且透明度介于 0 与 1 之间，标题栏高度介于展开高度与单行高度之间


### Scenario: 滚动回到页面顶部恢复多行

Given 标题栏已收拢为单行并固定在顶部
When 用户向上滚动回到页面顶部
Then 标题栏连续展开，恢复多行完整标题展示且不出现省略号

验收：A3

### Scenario: 在其它 Tab 内向下滚动同样收起

Given 详情页处于页面顶部且标题栏为多行展开态
When 用户在「磁链下载」「短评」或「相关清单」Tab 内向下滚动离开顶部
Then 标题栏同样收拢为单行省略并固定可见，TabBar 固定在其下方

验收：A4

### Scenario: 收起后标题栏固定可见

Given 详情页已向下滚动且标题栏为单行收起态
When 用户继续向下滚动任意 Tab 内容
Then 标题栏保持在页面顶部固定可见，不会被内容滚走

验收：A5

### Scenario: 收起态返回按钮可用

Given 标题栏已收拢为单行并固定在顶部
When 用户点击标题栏左上角的返回按钮
Then 页面返回上一页，行为与改动前的 AppBar 返回一致

验收：A2

## 边界与不变量

- 详情页加载中与加载失败状态保持现状，不渲染标题栏；不影响既有加载、错误重试逻辑。
- 标题栏两种形态共用同一标题文案与样式，仅行数、高度、省略状态与透明度随折叠进度变化。
- 不新增文案、本地化、字体或第三方依赖；不修改其他页面（演员详情、资讯详情等）的标题栏。
- 应用根级 `AnnotatedRegion` 与主题状态栏样式不变。

### Scenario: 大字号下标题栏不溢出

Given 系统文本缩放倍率为 2.0
When 详情页在顶部展开态与滚动收起态下渲染
Then 标题栏与页面不出现布局溢出异常，标题仍按多行/单行规则展示

### Scenario: 加载中与失败状态不受影响

Given 详情数据尚未返回或请求失败
When 详情页渲染加载中或错误重试界面
Then 页面保持既有的加载/错误重试表现，不出现标题栏且不产生额外异常
